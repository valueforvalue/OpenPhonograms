# OpenPhonograms Logo

The OpenPhonograms logo (stylized "ō" + open book) and wordmark are part of
the OpenPhonograms project and are released under the same MIT License as
the curriculum content.

## Files

- `openphonograms-logo.svg` — Full logo with icon + wordmark + tagline
- `openphonograms-icon.svg` — Icon-only for favicons and small placements
- `openphonograms-logo-1x.png` (placeholder) — 512px raster fallback
- `openphonograms-logo-2x.png` (placeholder) — 1024px raster fallback
- `openphonograms-logo-3x.png` (placeholder) — 1536px raster fallback

PNG files can be generated from the SVG using any standard tool
(Inkscape, rsvg-convert, etc.). Until then, the SVG is the canonical format
and is used directly in all PDF and HTML rendering.

## Color palette

- Primary: `#2a5c8a` (deep blue)
- Light: `#4a7caa`
- Gold accent: `#c8a832`
- Ink: `#222`
- Paper: `#fdfdfb`
