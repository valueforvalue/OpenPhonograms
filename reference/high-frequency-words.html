The principle

No word needs to be memorized as a visual shape. Every high-frequency word can be explained through its phonograms and spelling rules. If the child doesn't have the rule yet, either teach the rule or note the exception and promise to explain it later.

Exception protocol

When a needed word uses a rule not yet taught:

  1. "This word has something we haven't learned yet."
  2. Teach as much as the known phonograms allow.
  3. Note the exception. Promise: "When we learn Rule 10, this will make sense!"
  4. When the rule arrives, revisit: "Remember was? Now we know why!"
