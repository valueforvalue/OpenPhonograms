Complete Phonogram Chart

75 basic phonograms · Print this page as a wall reference · Sounds listed in order of frequency (most common first) · sound notation

How to use

Flash each card. Child says all sounds in order within 2 seconds. Hesitation = that phonogram needs more practice. Never accept just the first sound.

Printing tips

Print on A4 or US Letter, color if possible. The five groups match the handwriting stroke families in the curriculum. Single-letter phonograms on white cardstock, multi-letter on colored — this visual distinction helps children categorize.
