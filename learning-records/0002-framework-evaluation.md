# Learning Record 0002: Framework Evaluation & Curriculum Revision

## Date
2026-08-04

## Context
User proposed a teaching framework with these parameters: 74 phonograms, 30 spelling rules, 25 single-letter phonograms, three-tier structure (single/multi/advanced), spelling aids per phonogram, worksheets with rules, decodable readers with diacritical marks in text, spelling aid sidebar, cohesive animal stories, Montessori-style images.

Evaluation against the canonical book revealed several discrepancies and design adjustments needed.

## Discrepancies Resolved
1. **Phonogram count:** User said 74 → canonical is **75** (current edition). Older editions listed 74; the difference is one multi-letter phonogram.
2. **Rule count:** User said 30 → canonical is **31**. Rule 31 (Schwa) was added in a later edition.
3. **Single-letter count:** User said 25 → canonical is **26** (a–z). User likely treated `q` as multi-letter-only since it always pairs with `u` as `qu`. The book lists `q` as a single-letter phonogram AND `qu` as a separate multi-letter phonogram.

## Design Adjustments Made to curriculum.md

### Added sections:
- **Decodable Reader Design Principles** — 6 constraints: phonogram lockstep, spelling aid sidebar, diacritical marks in warm-up only, cohesive animal stories, Montessori-style images, page density
- **Phonogram-Rule Mapping** — definitive table of which phonograms have governing rules (spelling aids) and which don't. Only ~20 of 75 phonograms carry a dedicated rule.

### Modified sections:
- **Multi-letter phonogram intro** — removed "74 or 75" ambiguity, affirmed 75 as canonical
- **Say-to-Spell** — strengthened from "use this" to "this is NOT optional," added exact introduction point (Stage 2, word "little")
- **Stage 1 phonogram intro** — added explicit interleaving note: multi-letter phonograms begin once ~15 single-letter phonograms are known, NOT after all 26

### Key design principles now encoded:
- Diacritical marks go in warm-up boxes, not story text — the child must decode without crutches
- Spelling aid = governing rule for ~20 phonograms; for the rest, the aid is knowing all sounds in frequency order
- Worksheets embed the 5-step Spelling Analysis loop; rule-work only appears on worksheets for phonograms that actually have rules
- Multi-letter phonograms interleave during single-letter sequence (not a separate phase)
- Say-to-Spell is essential from the first multi-syllable word onward
