What is this?

A complete, print-first reading curriculum covering Pre-K through Grade 3+. Every lesson, worksheet, reader, and reference is generated from version-controlled data — no DRM, no internet required, no locked PDFs.

The methodology: spelling drives reading. Children learn the 75 phonograms (sound-units) and 31 spelling rules that govern 98% of English words. They practice a 5-step Spelling Analysis routine that turns spelling into a decoding tool for reading.

"Speech-to-print, not print-to-speech. Start with the sound; find the written form."
— Six core methodology ideas

How teachers use it

  1. Open the ZIP → read 00-Start-Here.pdf
  2. Run the placement test (09-Quick-Checks/placement-test.pdf) to find your child's starting stage
  3. Print the prep checklist for your stage (one page per stage folder)
  4. Open lesson pack #1 — each pack bundles cover + teacher script + worksheet + flash cards
  5. Print the phonogram chart and spelling rules poster for the wall (04-Quick-Reference/)
  6. Open the phonogram trainer (11-Game/phonogram-trainer.html) for fun practice

Methodology highlights

  • Speech-to-print, not print-to-speech. Start with the sound; find the written form.
  • Teach ALL sounds from the start. "a says /ă/ /ā/ /ä/" — never "a says /ă/" with more later.
  • Spelling drives reading. The 5-step Spelling Analysis is the core routine.
  • No sight words. Every English word can be decoded with phonograms + rules.
  • Say-to-Spell is not optional. Multi-syllable words need deliberate mispronunciation to hear their spelling.
  • One new thing per lesson. Never two phonograms or two rules in one lesson.

For developers

The full source is at github.com/valueforvalue/UncoveringtheLogic. Every PDF is generated from Markdown by Python scripts. Modify the catalog or generator, run just all, get a fresh release in ~2 minutes.

  • framework/lesson-catalog.csv — 248-row source of truth
  • scripts/generate-*.py — 9 generators (data → Markdown)
  • framework/render.py — Markdown → PDF via WeasyPrint
  • scripts/build-lesson-pack.py — per-lesson cohesive bundles
  • scripts/build-release.py — LOE-style release ZIP
  • justfile — 35+ build recipes

See docs/BUILD.md for full setup instructions.
