# Logic of English — 5-Minute Mental Model

For contributors new to this project.

## The Big Idea

English spelling is 98% predictable when you know 75 phonograms + 31 rules. This curriculum teaches those 106 tools systematically.

## How It's Different From Other Phonics

1. **Speech-to-print**, not print-to-speech. Start with the sound, find the spelling.
2. **All sounds from the start.** Never teach "a says /ă/" — teach all 3 sounds immediately.
3. **No sight words.** Every word is decodable. Even "the" and "of" have explanations.
4. **Spelling drives reading.** The core routine is Spelling Analysis (hear→segment→write→analyze→read).
5. **Say-to-Spell.** Deliberately mispronounce words to hear their spelling. /ə-bout/ → "ā-bout."

## Key Numbers

- 75 basic phonograms (26 single-letter + 49 multi-letter)
- 31 spelling rules
- 44 phonemes (speech sounds)
- 244 lessons across 5 stages
- 98% of English words covered

## The 5 Stages

1. **Pre-K:** Hearing sounds, learning a-z phonograms (no reading yet)
2. **K:** CVC words, first multi-letter phonograms (sh, th, ck, ee...)
3. **Gr 1:** Silent E (9 reasons), vowel teams, syllable division
4. **Gr 2:** Schwa, suffixing rules, Latin /sh/, prefixes/suffixes
5. **Gr 3+:** Latin/Greek roots, fluency, composition, grammar

## Critical Distinctions

- "Say-to-Spell" ≠ pronunciation. It's a deliberate tool.
- "Decodable" ≠ levelled. Decodable = only taught phonograms.
- "Spelling Analysis" ≠ spelling test. It's instruction, not assessment.
- "Phonogram" ≠ letter. sh is a phonogram but not a letter.
- "Rule" ≠ exception-based guideline. 98% coverage, not "i before e."
