## New Learning: The Root **port**

### Where It Comes From

**port** is a **Latin** root that means **"carry"**.

PORT means 'carry.' A porter carries luggage. A transport carries goods. An import is carried IN, an export is carried OUT.

### Word Builder

| Word | Prefix | Root | Suffix | Meaning |
|------|--------|------|--------|---------|
| transport | trans (across) + port | carry across |
| portable | port + able | able to be carried |
| import | im (in) + port | carry in |
| export | ex (out) + port | carry out |
| report | re (back) + port | carry back / tell |
| porter | port + er | one who carries |
