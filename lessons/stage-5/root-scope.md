## New Learning: The Root **scope**

### Where It Comes From

**scope** is a **Greek** root that means **"see"**.

SCOPE means 'see' (Greek). A telescope sees far. A microscope sees small things. A periscope sees around.

### Word Builder

| Word | Prefix | Root | Suffix | Meaning |
|------|--------|------|--------|---------|
| telescope | tele (far) + scope | far-seer |
| microscope | micro (small) + scope | small-seer |
| periscope | peri (around) + scope | around-seer |
| kaleidoscope | kalos (beautiful) + eidos + scope | beautiful-form seer |
| horoscope | horo (hour) + scope | hour-seer / astrology |
| stethoscope | stetho (chest) + scope | chest-seer / doctor's tool |
