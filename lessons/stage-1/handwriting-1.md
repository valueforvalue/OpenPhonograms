## ## Clockface Letters

These letters all start with a curve — like the face of a clock! The letters are: **a, d, g, c, o, qu, s** Letters



### How to Write Each Letter

### a
Start at the midline. Curve around like a clock going counter-clockwise. Go up and down in a straight line.

### d
Start at the midline. Curve around like a clock. Go up high, then straight down.

### g
Start at the midline. Curve around like a clock. Go up, then curve down into a tail below the line.

### c
Start just below the midline. Curve around like most of a clock. Leave a small opening.

### o
Start at the midline. Curve around like a clock. Close the circle neatly.

### qu
q: Curve around like a clock, then a short diagonal line. u: Curve down and back up. They are a team!

### s
Start just below the midline. Curve left, then right, like a snake.
