## Quick Start (5 Minutes)

1. **Read** `curriculum.md` — the full scope, sequence, and methodology (55KB reference)
2. **Print** the phonogram chart: `reference/phonogram-chart.html` 
3. **Print** the spelling rules: `reference/spelling-rules.html`
4. **Open** your stage's lesson files in `lessons/stage-X/`
5. **Generate PDFs:** `python framework/render.py --stage 1`

That's it. Everything else is in the lesson files.

## Stage-by-Stage Overview

### Stage 1: Phonemic Awareness & First Phonograms (48 lessons, Pre-K)

**Before starting:** Child should speak in complete sentences, follow two-step directions, and hold a pencil.

**What you do each lesson (15-20 minutes):**

| Step | Time | Activity |
|------|------|----------|
| 1 | 2 min | Phonogram flash review (say ALL sounds) |
| 2 | 5 min | Introduce new phonogram OR phonemic awareness game |
| 3 | 5 min | Writing practice / sand tray |
| 4 | 3 min | Review + quick check |

**Lesson types in Stage 1:**

| Lessons | Type | Description |
|---------|------|-------------|
| 1-8 | Phonemic awareness | Environmental sounds, blending, segmenting — NO letters yet |
| 9-14 | Group 1 phonograms | a, d, g, c, o, qu — clockface letters |
| 15 | Review | Group 1 review game |
| 16-21 | Group 2 phonograms | s, t, i, p, u, j — straight-start letters |
| 22 | Review | Group 2 review game |
| 23 | PA check-in | Final sounds in words |
| 24-29 | Group 3 phonograms | r, n, m, e, l, b — loops and bumps |
| 30 | Review | Group 3 review game |
| 31 | PA check-in | Middle sounds in words |
| 32-37 | Group 4 phonograms | h, k, f, v, w, x — tall/diagonal |
| 38 | Review | Group 4 review game |
| 39-40 | Group 5 phonograms | y, z — final group |
| 41 | PA check-in | Sound swapping game |
| 42 | Concept | Meet the vowels |
| 43 | Review | All 26 phonograms review |
| 44-45 | PA check-in | Blends + two-syllable blending |
| 46-47 | Handwriting | Clockface + straight-start letter formation |
| 48 | Assessment | Stage 1 mastery check |

**Materials to prepare:** Phonogram cards for a-z (text-based — print from any phonogram lesson), sand tray or whiteboard, letter formation guide.

**When to move on:** Child says all a-z sounds within 2 seconds, segments/blends CVC words orally, identifies initial/final/medial sounds.

## Daily Routine Reference

### Every Lesson Has These Components

1. **Phonogram flash review** — 2-5 minutes. Child sees card, says ALL sounds in frequency order.
2. **New learning** — Introduce ONE concept. Never two new things in one lesson.
3. **Spelling Analysis** — The heart of the lesson. 5-step routine (hear-segment-write-analyze-read).
4. **Reading practice** — Decodable words and sentences using known phonograms.
5. **Quick check** — Verify understanding before moving on.

### Spelling Analysis (Every Lesson)

| Step | Teacher | Student |
|------|---------|---------|
| 1. Hear & Say | Say word. Use in sentence. | Repeat. |
| 2. Segment | Hold up fingers (1 per sound). | Break word into sounds. |
| 3. Write | Watch student write. | Write phonograms. |
| 4. Analyze | "What rules? Underline multi-letter PGs." | Identify phonograms + rules. |
| 5. Read | "Read it sound by sound, then blend." | Sound out, then blend. |

### Say-to-Spell (Stages 3+)

For any word with schwa: say word normally → pronounce with clear vowels → segment → write → read normally.

## Troubleshooting Quick Reference

| Problem | Likely Cause | Fix |
|---------|-------------|-----|
| Child can't blend CVC | Not enough PA practice | Return to Stage 1, lessons 6-7 |
| Mixes up b/d, p/q | Visual confusion | Separate by at least 1 week; use multi-sensory tracing |
| Guesses at words instead of sounding out | Sight word habit | Go back to sound-by-sound; no guessing allowed |
| Can't remember phonogram sounds | Not enough flash review | 5 min daily flash drill. Say ALL sounds each time. |
| Spells 'mak' for 'make' | Silent E not internalized | Return to Stage 3, lesson 3. Practice the reason. |
| Says /ā/ for 'a' in 'cat' | Taught short sound after long | Always teach ALL sounds from the start. |
| Reads robotically (no fluency) | Needs repeated reading practice | Use Stage 5 fluency passages; time and re-read. |
| Can't spell multi-syllable words | Not using say-to-spell | Model say-to-spell for EVERY schwa word. |

More in: `reference/troubleshooting.html`

## Philosophy Reminders

1. **Speech-to-print, not print-to-speech.** Start with the sound, find the written form.
2. **Teach ALL sounds from the start.** Never say "a says /ă/" — always say "a says /ă/ /ā/ /ä/."
3. **Spelling drives reading.** Spelling Analysis is the core routine.
4. **No sight words.** Every word can be explained with phonograms and rules.
5. **Say-to-Spell is not optional.** Schwa appears in the majority of multi-syllable words. Without say-to-spell, the child cannot hear the spelling.
6. **Never skip phonemic awareness.** Even if the child knows letters, sound discrimination is the foundation.
7. **One new thing per lesson.** Never introduce two phonograms or two rules in one lesson.
